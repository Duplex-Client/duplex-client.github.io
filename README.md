# Duplex Labs

Duplex Client is a powerful client that has to faces, one for the end user and one for the developer. The end user can use the Duplex Client GUI, it does everything for them, while the developer can use the Duplex Server to create their own GUI and have full control over the Duplex Client, the developer can later publish their GUI and share it with the world.

how to use (user friendly):
  - Download the GUI Build
  - run the DuplexClient.exe
  - Have fun and enjoy the experience!

Developer:
  - Read the documentation.
  - Download DuplexServer.exe and run it.

Vibe coders:
  - Copy paste AI.md, adapt your style and alter it to your liking.
  - Give DOCUMENTATION.md to the AI and ask it to generate what you described.
